# Pour démarrer dans Claude Code

1. Ouvre ce dossier (`handoff-claude-code`) dans un terminal, ou copie son contenu à la racine du futur projet.
2. Lance Claude Code et colle le message ci-dessous.

---

Salut ! On va coder mon portfolio Flaura.dev. Tout le contexte est dans CLAUDE.md, la maquette validée est dans maquette/maquette-yozakura.html et les images dans assets/.

Avant d'écrire du code :
- lis CLAUDE.md et la maquette en entier ;
- propose-moi la stack finale, l'arborescence du projet et le découpage en composants ;
- liste les points sur lesquels tu as besoin d'une décision de ma part (hébergement, service d'envoi d'e-mails, etc.) ;
- dis-moi ce qui te paraît discutable dans la maquette, sans détour.

On avance ensuite section par section, en commençant par la base (thème clair/sombre, polices, layout, navigation), et tu me montres le résultat à chaque étape.
